STATUS: JANGAN PUSH KE REPO PUBLIK SEKARANG

Dewan menemukan 5 celah kritis tersembunyi yang meruntuhkan postur keamanan jika di-push ke GitHub. Semua penasihat bulat menuntut Gate 1 Patch sebelum rilis.

1. Konsensus Bulat Dewan (Where the Council Agrees)

Celah / Blind Spot Dampak Jika Di-Push ke GitHub Tingkat Risiko
Hardcoded Fallback JWT Secret (lib/auth.ts) Fallback string bocor di git publik; penyerang bisa memalsukan token admin instan jika env var kosong saat deploy. CRITICAL
Perimeter API Middleware Bocor (middleware.ts) Matcher hanya /admin/:path*, endpoint backend /api/admin/* tidak tersaring middleware. CRITICAL
In-Memory Rate Limiting Sia-sia (login/route.ts) State memori lokal reset di arsitektur cloud/serverless; register & laporan tanpa rate limit membuka banjir DoS. HIGH
Logout Palsu / Zombie Session (logout/route.ts) Delete cookie tanpa deklarasi eksplisit path: '/' diabaikan banyak browser; sesi tetap aktif. HIGH
Absennya Validasi Geospasial & Enum Koordinat TPS mentah tanpa bounds dan kecamatan bebas memicu Leaflet client-side crash dan polusi DB. MEDIUM

2. Perdebatan & Friksi Antar Penasihat (Where the Council Clashes)

  • Base64 7MB di MySQL vs Object Storage: The Expansionist & First Principles menuntut migrasi arsitektur ke S3/GCS seketika karena MySQL LongText akan mencekik InnoDB buffer pool. The Executor & Contrarian berpendapat migrasi S3 memakan waktu; langkah taktis sebelum push adalah memangkas ukuran payload maksimal ke 2MB dan menerapkan cooldown/rate limit.
  • Autentikasi Bearer Token: Usulan mendukung header Authorization untuk integrasi mobile ditolak mayoritas penasihat sebagai *scope creep* yang memperlebar attack surface saat ini.

3. Rencana Aksi Langsung (Immediate Gate 1 Action Plan)

1. Fail-Closed JWT Secret (lib/auth.ts)

Hapus fallback string publik. Paksa aplikasi gagal boot (throw new Error) di production jika JWT_SECRET belum disetel di environment.

2. Perluas Matcher Middleware (middleware.ts)

Ubah matcher menjadi matcher: ['/admin/:path*', '/api/admin/:path*'] agar seluruh API administratif terlindungi.

3. Perbaiki Pembersihan Cookie (app/api/auth/logout/route.ts)

Setel cookie dengan atribut maxAge: 0, path: '/', httpOnly: true untuk memastikan sesi bersih di semua browser.

4. Rate Limiting Registrasi & Laporan

Tambahkan pembatasan frekuensi pada POST /api/auth/register dan cooldown anti-duplikasi pada POST /api/laporan.

5. Bounding Box & Validasi Input Ketat

Batasi koordinat TPS dalam batas wajar Samarinda/Kaltim (-2.5 s/d 2.5, 113.5 s/d 119.0), validasi enum kecamatan, dan regex jam operasional /^([01]\d|2[0-3]):[0-5]\d$/.

Analisis Lengkap Kelima Penasihat Independen

1. The Contrarian (Red-Team Adversarial Lens) ▾

Patch keamanan ini memberikan rasa aman palsu (security theater). Fallback secret dlh-samarinda-secret-jwt-key-2026 adalah bom waktu. Jika environment variable gagal dimuat, seluruh proteksi runtuh—siapa pun bisa memalsukan token admin secara instan.

Matcher hanya mengunci /admin/:path*, rute backend kritis /api/admin/* sama sekali tidak tersentuh middleware. Rate limit di memori pada serverless Next.js tidak berguna karena counter reset tiap instance baru. Menerima 7MB base64 tanpa batasan frekuensi adalah resep OOM crash dan disk bloat.

2. The First Principles Thinker (Fundamental Architecture Lens) ▾

Arsitektur TROPIS berasumsi bahwa rute halaman adalah pelindung API, memori lokal adalah state global, dan database relasional adalah tempat penampungan biner. Ketiga asumsi ini cacat secara fundamental.

Mengizinkan upload Base64 hingga 7MB langsung ke kolom LongText MySQL tanpa throttling akan mencekik InnoDB buffer pool, memicu saturasi IOPS, dan berujung memory exhaustion (OOM). Solusi first-principles: Fail-closed JWT secret, guard auth terpusat di data layer, dan alihkan file ke Object Storage.

3. The Expansionist (Scalability & Civic Load Lens) ▾

Menyimpan payload base64 7MB pada kolom LongText MySQL adalah bom waktu skalabilitas sipil. Ketika ribuan warga Samarinda serentak melaporkan tumpukan sampah pasca-banjir, ukuran tabel akan meledak ratusan gigabyte dalam hitungan minggu, memicu kegagalan backup dan max_allowed_packet error.

Bulk update TPS tanpa prisma.$transaction dan tanpa validasi format waktu menciptakan risiko korupsi data laten yang merusak jadwal logistik armada truk sampah di lapangan.

4. The Outsider (Fresh Eyes & Production Traps Lens) ▾

Adanya fallback string dlh-samarinda-secret-jwt-key-2026 adalah dosa arsitektur terburuk. Begitu repo di-push ke GitHub publik, token admin dapat dipalsukan siapa saja secara instan. Hapus total default string tersebut—paksa runtime melempar fatal exception saat startup.

Menghapus cookie session_token tanpa parameter eksplisit path: '/' kerap diabaikan browser. Koordinat TPS mentah tanpa batas ketat menjamin Leaflet client-side crash seketika saat menerima data korup atau typo ekstrem.

5. The Executor (Immediate Practical Patch List) ▾

Jangan push ke GitHub sekarang. Deployment ini masih bocor. Terapkan daftar 5 patch konkret: Fail-closed JWT_SECRET, perbaiki matcher middleware untuk mengikutsertakan /api/admin/:path*, koreksi pembersihan cookie logout, terapkan validasi Zod/enum pada kecamatan dan koordinat TPS, serta pasang proteksi rate limiting/cooldown pada registrasi dan pelaporan.
